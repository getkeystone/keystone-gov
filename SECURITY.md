# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Keystone, please report it responsibly.

Email: [arnaldo@getkeystone.ai](mailto:arnaldo@getkeystone.ai)

Please include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact

I will acknowledge receipt within 48 hours and provide an initial assessment within 7 days.

## Supported Versions

Only the latest release on the main branch receives security updates.
